# Five Safeguards Against Incorrect LLM Answers

1. **Use trusted sources:** Ground factual answers in reliable documents or verified references.
2. **Require uncertainty:** Instruct the model to say "I don't know" when evidence is insufficient.
3. **Validate outputs:** Check generated JSON and structured data against a schema.
4. **Verify calculations:** Use Python or a calculator to independently check numerical answers.
5. **Test before deployment:** Evaluate the model on representative examples and review incorrect answers.

These safeguards reduce risk but do not guarantee that every model response will be correct.
