# Model Recommendations

## 1. Public Customer-Support Chatbot

**Recommendation: Gemini API**

- It can be integrated into a Python application through an API.
- It can generate natural-language answers to customer questions.
- The application can use a system prompt to guide its response style and behavior.
- API usage costs depend on the model, token counts, and current pricing.
- Customer data should be handled according to the provider's terms and the organization's privacy requirements.

## 2. Private On-Premises Chatbot

**Recommendation: Meta Llama with self-hosting**

- Llama offers models with downloadable weights under model-specific license terms.
- A compatible model can be deployed on infrastructure controlled by the organization.
- Self-hosting provides greater control over data storage and access.
- Hardware resources are needed to run the model.
- The selected model's license, performance, and hardware requirements must be checked before deployment.
