## Task 2: LLM Capabilities and Limitations

This task explores five common LLM capabilities:

- Summarization
- Text classification
- Information extraction
- Translation
- Code generation

It also examines limitations such as hallucinations, bias, context-window constraints, privacy risks, and output reliability.
